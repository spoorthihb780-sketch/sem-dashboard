# Semantic HTML5 & Accessible Enterprise Dashboard

## Project Overview

This project is an accessible enterprise dashboard built using semantic HTML5 and WCAG 2.1 accessibility principles.

The dashboard contains a navigation header, sidebar, main content area, data tables, accessible forms, and an accessible dialog component.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- WCAG 2.1 Accessibility Guidelines
- W3C HTML Validator
